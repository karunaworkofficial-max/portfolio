# Graphic Designer Portfolio - Deployment Guide

This document outlines the exact steps to take this portfolio live using modern, free-tier friendly infrastructure: Vercel (Frontend), Render (Backend), MongoDB Atlas (Database), and Cloudinary (Images).

---

## 1. MONGODB ATLAS (Database)
*Create this first to get your connection string.*

1. Go to [MongoDB Atlas](https://www.mongodb.com/cloud/atlas/register).
2. Create a **New Project** and build a **Free M0 Cluster**.
3. Under **Database Access**, create a new database user. Save the **Username** and **Password**.
4. Under **Network Access**, add a new IP address: `0.0.0.0/0` (This allows Render to connect dynamically).
5. Go back to your Cluster, click **Connect** → **Connect your application**.
6. Copy the connection string. Replace `<password>` with your actual password.
   *Example:* `mongodb+srv://admin:MySecurePass123@cluster0.mongodb.net/portfolio?retryWrites=true&w=majority`

### Recommended Indexes
Once connected (or via MongoDB Compass), create the following indexes for performance:
- `projects` collection: Index `{ order: 1 }` and `{ category: 1 }`
- `messages` collection: Index `{ read: 1 }` and `{ createdAt: -1 }`

---

## 2. CLOUDINARY (Images)
*Set this up to host your high-res design assets.*

1. Create a free account at [Cloudinary](https://cloudinary.com/).
2. On your dashboard, note down your **Cloud Name**, **API Key**, and **API Secret**.
3. (Optional but Recommended): Under Settings → Upload, create an **Upload Preset** specifically for your portfolio to automatically apply baseline compression, or leave it blank and let our `OptimizedImage` component handle transformations on the fly.
4. **Folder Structure**: Inside Cloudinary, create a folder named `portfolio` to keep things organized.

---

## 3. RENDER (Backend Node.js API)

1. Push your full repository (frontend and backend) to GitHub.
2. Go to [Render](https://render.com/) and create a **New Web Service**.
3. Connect your GitHub repository.
4. Settings:
   - **Root Directory**: `server`
   - **Environment**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `node server.js`
5. **Environment Variables** (Add these under Advanced):
   - `PORT`: `10000`
   - `NODE_ENV`: `production`
   - `MONGO_URI`: `[Your MongoDB Connection String]`
   - `JWT_SECRET`: `[A long, secure random string]`
   - `CLOUDINARY_CLOUD_NAME`: `[Your Cloudinary Cloud Name]`
   - `CLOUDINARY_API_KEY`: `[Your Cloudinary API Key]`
   - `CLOUDINARY_API_SECRET`: `[Your Cloudinary API Secret]`
   - `CLIENT_URL`: `[Leave blank for now, you will update this after Vercel deployment]`
6. **Health Check Path**: `/api/health`
7. Click **Deploy**. Once it's live, copy the Render URL (e.g., `https://portfolio-api.onrender.com`).

---

## 4. VERCEL (Frontend React App)

1. Go to [Vercel](https://vercel.com/) and click **Add New Project**.
2. Import your GitHub repository.
3. Settings:
   - **Framework Preset**: Vite
   - **Root Directory**: `client`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. **Environment Variables**:
   - `VITE_API_URL`: `[Your Render URL]/api` (e.g., `https://portfolio-api.onrender.com/api`)
5. Click **Deploy**.
6. Note your live URL (e.g., `https://portfolio.vercel.app`).
7. **CRITICAL:** Go back to Render, and update your backend `CLIENT_URL` environment variable to match your Vercel URL (to fix CORS issues).

---

## 5. POST-DEPLOYMENT GUIDE

### 1. Seeding the Database
You need an initial admin user to log in. You can run this script locally pointing to your production DB, or run it via a Render shell:
```bash
cd server
export MONGO_URI="[Your Production Mongo URI]"
node seed.js
```
*Login with the credentials generated by the seed file.*

### 2. Connect a Custom Domain
- In Vercel, go to your project → **Settings** → **Domains**.
- Add your custom domain (e.g., `john-doe-design.com`).
- Vercel will give you a CNAME or A Record to add to your domain registrar (GoDaddy, Namecheap, etc.).

### 3. Adding Your First Project
1. Go to `https://[your-domain]/admin/login` and log in.
2. Go to **Profile Settings** to update your name, bio, and upload a profile photo.
3. Go to **Projects** → **Add New Project**. Upload your first high-res thumbnail.
4. Go to **Theme Settings** to configure your 3D particles and color scheme.

## 6. PRODUCTION CHECKLIST ✅

Before sharing your link, verify the following:

- [ ] CORS is correctly configured (Backend `CLIENT_URL` matches Frontend exact URL without trailing slash).
- [ ] MongoDB Network access allows IP `0.0.0.0/0`.
- [ ] JWT secret is secure and not easily guessable.
- [ ] `/api/health` returns `200 OK`.
- [ ] Try logging into the `/admin` portal.
- [ ] Upload a test image to ensure Cloudinary keys are correct.
- [ ] Ensure 3D homepage works on mobile (no memory crashes).
- [ ] Submit a test Contact Form message and verify it appears in your Inbox.
- [ ] Verify meta tags using [HeyMeta](https://heymeta.com) for SEO.
